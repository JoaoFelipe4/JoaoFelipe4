## 👨‍💻 Sobre Mim

Engenheiro de Nuvem (AWS) na **SoftwareOne** e graduando em **Engenharia da Computação** pela UNA, com formação técnica em Eletrônica pelo **CEFET-MG**.

Possuo experiência sólida na arquitetura, sustentação e automação de ambientes de missão crítica em nuvem pública (AWS), com foco em:
- **Governança & Multi-Account:** Implementação de estruturas corporativas escaláveis com AWS Organizations e Control Tower.
- **Segurança & Conformidade:** Centralização de monitoramento e resposta a incidentes com GuardDuty, Security Hub, Inspector e IAM granular (Cross-Account Roles com External ID).
- **Infraestrutura como Código (IaC) & CI/CD:** Automação de provisionamento com Terraform (Cloud/CLI) e pipelines com GitHub Actions.
- **FinOps & Eficiência Operacional:** Redução de custos e rightsizing de recursos computacionais (EC2, ECS, EKS, Lambda) orientados a métricas com AWS Compute Optimizer e CloudWatch.
- **Engenharia de Software:** Desenvolvimento de soluções SaaS multi-tenant e microsserviços modernos com Node.js, TypeScript e bancos NoSQL/SQL.

## 📌 Projetos em Destaque

### 🏥 [Medical Appointment System - Arquitetura de Microsserviços](https://github.com/JoaoFelipe4/tcc-2025-microservices)
Arquitetura completa de microsserviços desacoplados (Auth, Doctors e Patients) em containers Docker orquestrados para deploy em nuvem via AWS ECS/ECR.
* **Stack:** Node.js, Express, MongoDB (NoSQL), Docker, AWS ECS/ECR, AWS Amplify Gen2.
* **Foco:** Isolamento de falhas, autenticação JWT, escalabilidade horizontal e esteiras automatizadas.

### 🌐 [Frontend Microservices Portal](https://github.com/JoaoFelipe4/tcc-2025-frontend-microservices)

* **Stack:** Angular, TypeScript, AWS Amplify Gen2, Tailwind CSS.
